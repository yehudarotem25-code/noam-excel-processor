# מעבד קבצי Excel - מדריך הפעלה

## תיאור המערכת
אפליקציית Streamlit לעיבוד קבצי Excel שמבצעת:
- איחוד מספר קבצים
- ספירת מופעים של IDs
- חיבור (Left Join) עם קובץ התייחסות
- יצוא תוצאות לקובץ Excel

## מה המערכת עושה?

### קלט:
1. **קבצי Type A** (Extensions ו-Endpoints) - מספר קבצי Excel שכל אחד מכיל עמודת ID
2. **קובץ Type B** (Reference) - קובץ Excel אחד עם 3 עמודות: ID, Date, Status

### תהליך:
1. המערכת מאחדת את כל קבצי Type A לרשימה אחת
2. סופרת כמה פעמים כל ID מופיע
3. מבצעת Left Join בין הספירה לקובץ Type B
4. מייצרת קובץ פלט עם 4 עמודות: ID, Date, Status, Count

### פלט:
קובץ Excel עם 4 עמודות בדיוק:
- **ID** - מזהה ייחודי (כמחרוזת)
- **Date** - תאריך מקובץ B
- **Status** - סטטוס מקובץ B
- **Count** - מספר המופעים של ה-ID בקבצי A

## התקנה והפעלה

### שלב 1: התקנת Python
וודא שיש לך Python מותקן (גרסה 3.8 ומעלה).
בדוק בטרמינל:
```bash
python --version
```

### שלב 2: יצירת סביבה וירטואלית (מומלץ)
```bash
# יצירת סביבה וירטואלית
python -m venv venv

# הפעלת הסביבה:
# ב-Windows:
venv\Scripts\activate
# ב-Mac/Linux:
source venv/bin/activate
```

### שלב 3: התקנת הספריות הנדרשות
```bash
pip install -r requirements.txt
```

### שלב 4: הפעלת האפליקציה
```bash
streamlit run excel_processor.py
```

האפליקציה תיפתח אוטומטית בדפדפן שלך בכתובת: `http://localhost:8501`

## הוראות שימוש

1. **העלאת קבצי Type A:**
   - לחץ על "Browse files" בצד שמאל
   - בחר את כל קבצי ה-Extensions וה-Endpoints שלך
   - ניתן לבחור מספר קבצים בבת אחת

2. **העלאת קובץ Type B:**
   - לחץ על "Browse files" בצד ימין
   - בחר את קובץ ההתייחסות (עם ID, Date, Status)

3. **עיבוד:**
   - לחץ על כפתור "עבד נתונים"
   - המערכת תציג התקדמות ומסרים על התהליך

4. **הורדת תוצאות:**
   - לאחר העיבוד, תוצג טבלת תוצאות
   - לחץ על "הורד קובץ Excel" לשמירת הקובץ

## דרישות למבנה הקבצים

### קבצי Type A:
- חייבים להכיל עמודה בשם `ID` (רישיות חשובה!)
- יכולים להכיל עמודות נוספות (יתעלמו)
- אותו ID יכול להופיע מספר פעמים

### קובץ Type B:
- חייב להכיל 3 עמודות:
  - `ID` - מזהה ייחודי
  - `Date` - תאריך
  - `Status` - סטטוס
- כל ID צריך להופיע פעם אחת בלבד

## טיפול בבעיות נפוצות

### הקובץ לא עולה
- וודא שהקובץ בפורמט Excel (.xlsx או .xls)
- בדוק שהעמודה נקראת `ID` ולא `id` או משהו אחר

### אפסים מובילים נעלמים
- המערכת מטפלת בזה אוטומטית על ידי המרת ID למחרוזת

### Count מראה 0
- זה אומר שה-ID קיים בקובץ B אבל לא הופיע בשום קובץ A

### שגיאה בעיבוד
- וודא שכל הקבצים תקינים ונפתחים ב-Excel
- בדוק שכל העמודות הנדרשות קיימות
